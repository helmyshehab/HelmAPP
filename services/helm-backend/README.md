# helm-backend

NestJS **TypeScript modular monolith** for Helm حلم (Step 2 skeleton).

- Domain modules under `src/modules/` (stubs only)
- Ports under `src/infrastructure/ports/`
- Mock adapters under `src/infrastructure/adapters/mock/` (**MOCK** — local MVP without paid APIs)
- Drizzle stub under `src/infrastructure/adapters/drizzle/`
- Live endpoints: `GET /v1/health`, `GET /v1/meta` only

No product feature flows in Step 2.
